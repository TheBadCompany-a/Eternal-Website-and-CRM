# Eternal Repos — Website

Care-first website for Eternal Repos (Tribute in Motion). Live: https://beta.eternalrepos.com

## Stack
Vite 6 + React 19 + TypeScript + Tailwind 4 + framer-motion + react-router.

## Develop
```
npm install
npm run dev
```

## Build
```
npm run build   # tsc + vite build -> dist/
```

## Deploy
Push to `main` — Vercel (project: eternal-website3) auto-builds and deploys to beta.eternalrepos.com.
